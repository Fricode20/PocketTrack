# PocketTrack

PocketTrack is a simple Android application that helps users track daily expenses and become more aware of their spending habits.

## Features (Version 1)

- Add Expense
- Edit Expense
- Delete Expense
- View Current Balance
- View Expense History
- View Weekly Spending
- View Monthly Spending

## Technology Stack

- Kotlin
- Android Studio
- MVVM Architecture
- Room Database
- XML Layouts
